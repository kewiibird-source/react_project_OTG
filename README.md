## 📌 프로젝트 소개

> 혼자서도 술을 즐겨 마시는 사람들의 모임 SNS

혼술을 하면서 자기만의 꿀정보나 레시피를 공유하고 싶을때,
가끔은 내가 갔던 술집이 너무 마음에 들어서 공유하고 싶을때,
내가 만들어보고 싶은 레시피나 정보를 한 플렛폼에서 볼 수 있으면 얼마나 좋을까? 

인스타 릴스, 유튜브 쇼츠로 많은 꿀팁·레시피가 많이 올라옵니다.
하지만 매번 저장해놓고 찾아보기 귀찮은게 단점이였죠
아예 술 전용 SNS가 있으면 좋을 것 같다는 생각을 했습니다. 

원하는 게시물을 저장해놓고, 해시태그를 이용해 검색할 수 있는 시스템

내가 좋아하는 술, 장소 등을 마음껏 공유할 수 있고
혼자서 마시는 술이지만 잔 너머에는 여러 사람들과 함께한다는 뜻으로 만들었습니다.

## ⭐ 프로젝트 주요 기능

<details>
<summary><b>1. 메인홈 화면</b></summary>
<br>

![홈피드](./assets/5.홈(피드).png)
- **사이드바 네비게이션:** 홈, 새 게시물, 알림, 보관함, 프로필 등 주요 메뉴로 빠른 이동
- **피드 뷰어:** 다중 이미지 슬라이더를 지원하는 사용자 맞춤형 피드
- **위젯 제공:** 우측 패널을 통해 '회원님을 위한 추천(팔로우 추천)' 및 '인기 게시물 TOP 5' 제공

</details>

<details>
<summary><b>2. 게시물 디테일 모달창</b></summary>
<br>

![게시물 디테일](./assets/14.게시물_디테일.png)
- **모달 UI:** 피드에서 게시글 클릭 시 페이지 이동 없이 모달창으로 상세 내용과 댓글 확인 가능
- **인터랙션:** 좋아요, 스크랩, 인용(리포스트) 기능 지원
- **댓글 시스템:** 대댓글 및 멘션(@닉네임) 작성이 가능하며 실시간 알림과 연동

</details>

<details>
<summary><b>3. 게시물 보관함</b></summary>
<br>

![보관함](./assets/8.프로필(보관함).png)
- **해시태그 및 보관함:** 게시글 해시태그 기반 검색 및 스크랩(보관함) 관리

</details>

## 💡 기술적 강조 포인트

- **트랜잭션 기반 무결성 보장:** 게시글 작성 시 텍스트, 다중 이미지(Multer), 해시태그 매핑을 하나의 트랜잭션으로 묶고, 에러 발생 시 업로드된 파일까지 롤백(fs.unlinkSync) 처리
- **정규화된 해시태그 설계:** 마스터 테이블(HASHTAGS)과 매핑 테이블(POST_HASHTAGS) 분리로 데이터 중복을 방지하고 검색 효율성 증대
- **소셜 로그인 계정 충돌 방지:** 기존 가입된 이메일과 다른 소셜 Provider로 접근 시, 중복 가입을 막고 올바른 계정 연동을 유도하는 분기 처리
- **정규식 파싱 기반 멘션 시스템:** 단순 알림을 넘어, 텍스트 내 `@닉네임`을 정규식으로 감지하고 추출하여 자동 알림 트리거 구현
- **안전한 토큰 및 상태 관리:** DB에 Refresh Token을 저장하고 필요시 Revoke(폐기) 처리하여 강제 로그아웃 등 강력한 세션 제어 구현, 전반적인 데이터 삭제에 Soft Delete 패턴(STATUS='DELETED')을 적용하여 복구 가능성 확보
